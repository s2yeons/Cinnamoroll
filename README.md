# Cinnamoroll — 3D Motion Character Page

하늘에서 날아온 하얀 강아지, 시나모롤을 소개하는 인터랙티브 팬 페이지.

- **three.js** — 캐릭터를 프리미티브 변형으로 직접 모델링 (노 모양 귀, 돔형 머리, 시나몬롤 꼬리), 커스텀 셀 셰이딩 + 픽셀 고정 두께 아웃라인, 인스턴싱 구름, 별/반짝이 셰이더
- **anime.js v4** — 로더 SVG 드로잉, 글자 분할 인트로, 3D 리액션(스쿼시 & 스트레치, 스핀, 플립), 카운터, 파티클
- **미니게임 SKY RUN** — 누르고 있으면 귀를 펄럭여 비행, 시나몬롤 수집·콤보·황금 롤·번개구름·최고 기록
- **잡아서 던지기** — 드래그로 던지면 과감쇠 없는 스프링 물리로 튕겨 돌아옴
- **WebAudio 합성 효과음** — 샘플 파일 없이 오실레이터·노이즈로 생성 (기본 OFF, 토글)
- **Lenis** — 스크롤 → 섹션별 포즈 키프레임 블렌딩 (하늘 색, 카메라, 귀 각도, 표정)

```bash
npm install
npm run dev
```
